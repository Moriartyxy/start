# Трекер Привычек

Простое и эффективное веб-приложение для отслеживания здоровых привычек.

## Возможности

### Отслеживаемые Привычки

1. **Контроль Питания** - ежедневная отметка о контроле переедания
2. **Бег** - запись дистанции и времени пробежек
3. **Велосипед** - запись дистанции и времени велопрогулок

### Функции

- **Серии (Streaks)** - автоматический подсчет последовательных дней выполнения привычек
- **Календарь** - визуализация последних 7 дней с цветовыми индикаторами
- **Статистика** - месячная статистика по всем привычкам
- **Локальное Хранение** - все данные сохраняются в браузере
- **Экспорт/Импорт** - возможность сохранения и восстановления данных

## Как Использовать

### Запуск

Просто откройте файл `index.html` в любом современном браузере.

### Контроль Питания

- Нажмите "Да" если день прошел без переедания
- Нажмите "Нет" если были срывы
- Карточка станет зеленой при успешном дне

### Бег и Велосипед

1. Введите дистанцию в километрах (например, 5.5)
2. Введите время в минутах (например, 30)
3. Нажмите "Сохранить"
4. Приложение автоматически рассчитает темп

### Календарь

- Зеленые точки - успешное выполнение
- Красные точки - отметка о переедании
- Серые точки - нет данных

### Статистика

Автоматически показывает за текущий месяц:
- Количество дней без переедания
- Количество тренировок
- Общие дистанции
- Общее время

### Экспорт и Импорт

- **Экспорт**: Сохраняет все данные в JSON файл
- **Импорт**: Восстанавливает данные из ранее сохраненного файла

## Технические Детали

- **HTML5** - структура приложения
- **CSS3** - адаптивный дизайн с градиентами и анимациями
- **Vanilla JavaScript** - вся логика без внешних зависимостей
- **LocalStorage API** - локальное хранение данных

## Браузерная Совместимость

Работает во всех современных браузерах:
- Chrome/Edge (рекомендуется)
- Firefox
- Safari
- Opera

## Приватность

Все данные хранятся локально в вашем браузере. Никакая информация не отправляется на внешние серверы.

## Советы

1. **Регулярность** - отмечайте привычки каждый день
2. **Честность** - будьте честны с собой для лучших результатов
3. **Резервные копии** - периодически экспортируйте данные
4. **Цели** - ставьте реалистичные цели и следите за прогрессом

## Разработка

Создано с использованием современных веб-технологий для максимальной простоты и эффективности.
