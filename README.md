# Трекер Привычек Pro

Продвинутое веб-приложение для отслеживания здоровых привычек с системой достижений и детальной аналитикой.

## Основные возможности

### Отслеживаемые привычки

1. **Контроль Питания** - ежедневная отметка о контроле переедания
   - Прогресс-бар месячной цели
   - Подсчет серий успешных дней
   - Процент успеха

2. **Бег** - полный мониторинг пробежек
   - Дистанция и время
   - Темп (мин/км)
   - Скорость (км/ч)
   - Калории
   - Месячная цель: 50 км

3. **Велосипед** - отслеживание велотренировок
   - Дистанция и время
   - Средняя скорость
   - Темп
   - Калории
   - Месячная цель: 100 км

## Как использовать

### Запуск

Откройте `index.html` в браузере или разверните на GitHub Pages / Netlify.

### Ежедневное использование

**Вкладка "Сегодня":**

1. **Контроль питания**
   - Нажмите "Да" или "Нет" в конце дня
   - Следите за серией успешных дней

2. **Бег/Велосипед**
   - Введите дистанцию (км)
   - Введите время (минуты)
   - Нажмите "Сохранить тренировку"
   - Увидите все метрики: темп, скорость, калории

**Вкладка "Прогресс":**
- Смотрите графики тренировок за неделю
- Отслеживайте личные рекорды
- Анализируйте календарь активности

**Вкладка "Достижения":**
- Открывайте новые награды
- Отслеживайте прогресс к целям
- Получайте мотивацию

**Вкладка "Статистика":**
- Переключайте периоды (неделя/месяц/все время)
- Анализируйте детальную статистику
- Планируйте следующие цели

### Экспорт/Импорт

- **Экспорт** - сохраняет все данные в JSON
- **Импорт** - восстанавливает из бэкапа
- Рекомендуется делать бэкапы регулярно
